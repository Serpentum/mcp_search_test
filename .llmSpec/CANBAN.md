## Задачи

### T001 — Инициализация проекта и requirements.txt
**Статус:** todo
**Описание:** Создать requirements.txt с точными версиями зависимостей: mcp, httpx, beautifulsoup4, trafilatura, duckduckgo-search
**Файл реализации:** requirements.txt

### T002 — Базовая структура MCP сервера
**Статус:** todo
**Описание:** Создать main.py с импортами, инициализацией Server, обработкой сигналов, базовым шаблоном инструментов
**Файл реализации:** main.py (каркас)

### T003 — Реализация инструмента web_search
**Статус:** todo
**Описание:** Реализовать web_search(query: str) — поиск до 5 результатов через duckduckgo-search, форматирование вывода с эмодзи, обработка пустых результатов
**Файл реализации:** main.py (web_search)

### T004 — Реализация инструмента fetch_url
**Статус:** todo
**Описание:** Реализовать fetch_url(url: str, format: str) — получение контента по URL, поддержка markdown/html, лимит 10000 символов
**Файл реализации:** main.py (fetch_url)

### T005 — Валидация URL и безопасность
**Статус:** todo
**Описание:** Блокировка file://, ftp://, localhost, 127.0.0.1, 0.0.0.0, частных IP-диапазонов. Проверка начала с http:// или https://
**Файл реализации:** main.py (url_validation)

### T006 — Обработка ошибок и логирование
**Статус:** todo
**Описание:** Обработка httpx.RequestError, duckduckgo_search.exceptions, общих исключений. Логирование в stderr. Структурированные сообщения об ошибках в TextContent
**Файл реализации:** main.py (error_handling)

### T007 — Обработка сигналов SIGINT/SIGTERM
**Статус:** todo
**Описание:** Graceful shutdown при получении сигналов прерывания
**Файл реализации:** main.py (signal_handler)

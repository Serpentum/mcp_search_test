# MCP Web Tools

MCP-сервер с двумя инструментами: поиск в интернете и загрузка содержимого страниц.

## Инструменты

- **web_search** — поиск через Google (до 5 результатов)
- **fetch_url** — загрузка содержимого веб-страницы (markdown или HTML)

## Лимиты

### Мягкие лимиты (advisory)

Модель получает рекомендацию остановиться, но технически может продолжить:

| Инструмент | Мягкий лимит | Поведение |
|------------|-------------|-----------|
| web_search | 5 вызовов | "Рекомендую прочитать найденные страницы и сформировать ответ" |
| fetch_url  | 8 вызовов | "Пожалуйста, завершите чтение и сформируйте ответ" |

### Жёсткие лимиты (hard)

Блокируют дальнейшее использование инструмента:

| Инструмент | Жёсткий лимит | Поведение |
|------------|--------------|-----------|
| web_search | 7 вызовов | "Лимит поисков исчерпан" |
| fetch_url  | 10 вызовов | "Лимит чтений исчерпан" |
| **Всего**  | **30 вызовов** | Общий лимит на все инструменты |

### Кэширование

- Результаты поиска кэшируются по точному совпадению query (TTL: 5 минут)
- Содержимое страниц кэшируется по URL + формату (TTL: 5 минут)
- Кэш-хиты **не тратят** счётчик вызовов
- Максимум 100 записей в кэше (LRU eviction)

### Прогресс в ответе

Каждый ответ содержит прогресс:

```
---
📊 Прогресс: поиски 2/7, чтения 3/10, всего 5/30
Осталось: 5 поисков, 7 чтений, 25 всего
```

## Конфигурация (env vars)

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `MCP_MAX_SEARCH_SOFT` | 5 | Мягкий лимит поисков |
| `MCP_MAX_SEARCH_HARD` | 7 | Жёсткий лимит поисков |
| `MCP_MAX_FETCH_SOFT` | 8 | Мягкий лимит чтений |
| `MCP_MAX_FETCH_HARD` | 10 | Жёсткий лимит чтений |
| `MCP_MAX_TOTAL` | 30 | Общий лимит вызовов |
| `MCP_CACHE_TTL` | 300 | TTL кэша в секундах |
| `MCP_CACHE_MAX_SIZE` | 100 | Максимум записей в кэше |
| `MCP_UNSAFE_MODE` | false | Отключает все проверки безопасности (localhost, частные сети) |

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python server.py
```

С конфигурацией через env vars:

```bash
MCP_MAX_SEARCH_SOFT=3 MCP_MAX_TOTAL=20 python server.py
```

## Подключение через MCP-клиент

```json
{
  "mcpServers": {
    "web-tools": {
      "command": "python",
      "args": ["D:/pets/mcp_search_test/server.py"]
    }
  }
}
```

## Примеры использования

### Поиск

```json
{
  "name": "web_search",
  "arguments": {
    "query": "Python programming"
  }
}
```

### Загрузка страницы

```json
{
  "name": "fetch_url",
  "arguments": {
    "url": "https://example.com",
    "format": "markdown"
  }
}
```

## Безопасность

- Блокировка `file://`, `ftp://` схем
- Блокировка localhost и частных IP-адресов
- Лимит вывода 10 000 символов для fetch_url
- Логирование в stderr
- `MCP_UNSAFE_MODE=true` отключает все проверки безопасности (только для изолированных сред)
